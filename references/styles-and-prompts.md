# 风格菜单与完整 Prompt

状态：以下五类是设计方案，不是五条参考的已验证风格归属。时长、速度和镜头长度都是可调起点；按实际音乐和素材调整。每个 prompt 可独立复制，供能实际读取素材的剪辑 Agent 使用。

| 模式 | 节奏与画面 | 炫酷来自哪里 | 适合素材 |
|---|---|---|---|
| A 柔光情绪 | 人声乐句牵引，柔光、留白，快慢交替 | 温柔音乐与利落枪法的反差 | 单点、甩枪、简洁双杀 |
| B 回忆拼贴 | 镜头呼应、画面嵌套、少量闪回 | 同构转场、画中画与时间感 | 多天/多地图/同一把枪的录屏 |
| C 冷色卡点 | 短句、停顿、切分，清冷高对比 | 变速落点、动作接力、少数强冲击 | 快速单杀、转火、位移 |
| D R&B 律动 | 松弛、弹性、轻暖色，跟随切分 | 枪声像打击乐，镜头与动作有律动 | 普通排位单杀、切枪、走位 |
| E 空灵爆发 | 氛围铺垫，drop 展开，冷色通透 | 景深感、长短镜头反差、一次视觉高潮 | 少量漂亮高光、狙击、技能动作 |

## A：柔光情绪

```text
请把我提供的 Valorant 素材剪成约40–60秒的柔光情绪流 montage。允许普通单杀、双杀和漂亮甩枪，不要求五杀。音乐以我提供的音源为准，以人声乐句组织段落，让温柔音乐和干净枪法形成反差。

前2秒给一个有吸引力的动作或画面，随后用短铺垫进入首个高光；中段快慢交替，最后用最有记忆点的一杀收束。镜头长度随乐句变化，不把每一个鼓点都剪成击杀。

使用轻柔泛光、通透中间调、少量颗粒；敌人与准星保持清楚。用转身方向、切枪姿态和相近构图连接不同片段。重音处可短促缩放、抽帧或光晕脉冲，随后回到清晰实速。慢动作放在开枪前的短暂悬停或命中后的余韵，不把全部交火拖慢。

文字少量出现，简短原创，随人声进入和退出；避免整屏连续歌词。保留少量质感枪声，压低杂乱聊天，结尾让音乐自然结束一个乐句。

先读取实际素材与音轨，输出带源时间码、音乐锚点和速度曲线的时间线，再制作预览。参考片无法播放时明确标记，这份方案作为设计提案，不声称复刻作者效果。保留原文件；只声明实际生成并检查过的交付物。
```

## B：回忆拼贴

```text
请用我的 Valorant 录屏制作45–60秒的回忆拼贴 montage，把不同时间的操作组织成一个有呼应的小作品。普通单杀、走位、切枪和地图空镜都可以使用，重点是结构和视觉创意。

开场展示一个短小的动作或画面母题，中段让它以不同地图或武器的形式重现，结尾回到同一构图形成闭环。开头控制在2–3秒内进入有吸引力的内容。用实际相似的准星位置、横拉方向、枪械运动或地图形状做匹配剪辑。

主要视觉手法只选两种，例如画中画嵌套加短闪回，或接触印样式拼贴加遮罩揭示。主操作始终有明确视觉中心。可以让辅助画面短暂冻结或变成细框缩略图，再由其中一个画面接管全屏。操作主体正常播放，不用倒放伪造击杀。

回忆层与当前层可有轻微色温和颗粒差异，但全片色彩统一。剪辑跟随音乐的乐句与重音；给高潮留强度，不在每个镜头重复同一个模板。文字只承担章节或情绪提示，使用原创短句。

先检查素材中是否真的有可匹配的动作；缺少时换转场方案，不编造源片段。列出具体源入出点、图层关系、音乐锚点，再交付预览与可继续修改的工程或时间线。参考未能播放时报告限制；保留原片，核查闪回与图层是否遮住关键击杀。
```

## C：冷色卡点

```text
请把我的 Valorant 素材剪成25–40秒的冷色卡点 montage，要短、锋利、有冲击力。普通单杀和双杀也能成为主镜头，优先选转火、甩枪、位移或开枪动作好看的片段。

开场0–2秒直接给漂亮动作，主段落跟随音乐的实际重音和切分。强段快速推进，中间安排一次短停顿或声音抽空，再进入最后的高潮。不要平均每秒切一次，也不要每杀都套同一个闪白。

把等待、转身或切枪适度加速，开枪前短暂减速，在命中处落回清晰画面。使用运动方向一致的甩镜、短遮罩切换、局部缩放与少量RGB分离。最强的两三个落点可以叠加短冲击、画面破碎或图形遮罩，其余镜头保持较低强度。效果参数依据分辨率和预览调整，命中前后能辨认敌人与瞄准关系。

调色清冷、通透、高对比，暗处仍可辨人。枪声与音乐重音形成打击感，但连续多杀保留真实动作顺序，不把不同回合包装成一个残局。歌词或标题做少量图形化排版，不盖住准星。

先输出实际素材与音乐对应的时间线及重点效果说明，再制作预览。检查变速接缝、音画卡点、插帧重影和高强度闪帧是否堆积。保留原片与旧版本；缺少可用工具时交付可执行方案并说明尚未渲染。
```

## D：R&B 律动

```text
请把我提供的 Valorant 素材制作成35–50秒的R&B律动 montage。整体轻松、帅气、有弹性，音乐用我提供的音源，跟随切分、贝斯与人声，不剪成全程重低音冲击。

挑选普通但干净的单杀、双杀、轻巧走位和切枪动作。按音乐短句组织镜头，保留少量自然停顿；有的击杀落在主拍，有的回应切分或人声停顿，由实际音轨决定。让枪声成为节奏的一部分，而不是用枪声淹没人声。

使用轻暖中性色、干净肤色与地图颜色，增加少量柔光即可。镜头以小幅弹性缩放、流畅推拉和方向匹配转场为主。变速尽量圆滑，交火核心回到实速，击杀后短暂停留再接下一个动作。重点落点可以突然切近或出现一句短文字，随后释放画面空间。

避免把松弛感剪成拖沓：删掉无意义跑图和长等待，用动作本身制造趣味。结尾让最后一杀、人物动作或切枪回应音乐收尾。

先读取实际素材，列出源时间码、音乐切分点、镜头顺序和音量处理，再做预览。参考视频未播放时仅将其作为用户审美索引，不声称已复刻。保留原始素材并核查音画同步、文字位置和导出流畅度。
```

## E：空灵爆发

```text
请把我的 Valorant 素材做成30–45秒的空灵爆发 montage。前段有空间感，主段随音乐展开，视觉高潮集中而鲜明。素材不必是职业操作，少量漂亮单杀、狙击或技能衔接也可以。

音乐使用我提供的音源。开场用1–3秒建立氛围并给一个吸引人的细节；选择实际存在的乐句上升或drop作为展开点，不凭空假设音乐有drop。高潮前短暂收紧声音与画面，展开时由局部构图或画框进入全屏，让关键命中与音乐重音相遇。

采用蓝青、银白或接近原片的冷色方案，通透而非整屏染蓝。用少量柔光、空间层次和速度反差营造空灵感。一次主视觉高潮可使用遮罩、局部残影或粒子装饰；准星和目标所在区域保持可辨。普通镜头以动作匹配、顺势推拉连接，让长镜头与短爆发交替。

前奏中的等待可压缩，命中瞬间恢复清晰，余韵处短暂慢放。低帧率素材减少慢动作，插帧异常立即换方案。最后一个重音后保留短余韵，音乐自然收束。

先给实际源片段、音乐锚点和主视觉高潮设计，再制作预览。时间码必须来自读过的素材；无法播放参考时明确说明这是创作方案。保留原片，检查过曝、拖影、关键目标可见性与音乐同步。
```

## 混合方式

优先让音乐决定主风格，素材决定转场和速度。例如A的柔光与C的高潮、B的拼贴与D的律动、E的铺垫与C的爆发。一个短片通常只需要一个主风格加一种辅助手法；用户明确要多段风格变化时，按音乐段落安排并说明衔接方式。
