# 风格菜单与完整 Prompt

状态：A–E 是初版设计方案，已用 [reference-videos.md](reference-videos.md) 的实测数据修订；F–H 是从 TikTok 和 B 站热门作品里新提炼的；I、J 是两种剪辑模式（流畅长镜头 / 一枪一剪卡点），依据 Esdeath、Winter 系列和 B 站、TikTok 高播放作品的实测。“相近参考”只表示观察到的特征相符，不表示作者自己这样分类。数字是可调起点，按实际音乐和素材调整。每个 prompt 可独立复制。

## 节奏基准（实测）

| 片长 | 剪/分钟 | 中位镜头 | 长镜头 (>4s) | 闪白 | 来源 |
|---|---|---|---|---|---|
| 8–30s 短卡点 | 70–100 | 0.4–0.55s | 0–1 个 | 集中在高潮 | R6、T4 |
| 35–55s 短片 | 35–60 | 0.47–1.0s | 0–3 个 | 集中在一个 5–10s 窗口 | R1、R4、T1–T3 |
| 2–4 分钟情绪长片 | 19–31 | 1.1–2.2s | 9–18 个，最长约 21s | 全片约 4–14 次 | R2、R3、R5、R7 |
| 80–135s 整回合 / 枪法实录 | 12–18（爆发窗口内约 50–55） | 1.3–3.1s | 6–10 个，最长 14–20s | 全片 4–7 次 | E1、E2、W1、W2 |
| S 一枪一剪卡点 | 43–65 | 0.4–0.6s | 0–8 个 | 视风格 | B站 174 万、44 万、33 万 |
| F 流畅长镜头（热门残局） | 7–18 | 1.3–7.2s | 多个，最长 18–33s | 少 | B站 60 万、@jrdude2007、@clip2eiko_fpss |

用法：先按目标时长定密度区间，再在高潮把局部密度提到区间上限以上。平段不放闪白。

|---|---|---|---|---|

| E 空灵爆发 | 长镜头铺垫，后段密集爆发 | 越来越亮、越切越密 | 少量漂亮高光、狙击 | R1、R3 |

| H 整活梗向 | 保留 HUD，几乎不调色 | 操作态度＋标注、定格笑点 | 嘲讽、反杀、离谱时机 | T2 |

| J 一枪一剪卡点 | S 模式：每杀一刀，开枪帧落拍，0.3–1.0 秒 | 神经枪的速度和断奏卡点 | 大量独立单杀 | B站《【瓦罗兰特】》174 万、APT |
| K 大转场情歌 | 长回合与一杀一刀爆发交替，回合间全用运动模糊大转场 | 情歌＋强转场＋败北自嘲结尾 | 连杀、残局和单杀都有 | 抖音 宇晖晖晖 第 4–8 集（337 万–959 万播放） |

不管选哪个风格，先按 [edit-modes.md](edit-modes.md) 定下整条视频用 S 模式还是 F 模式，全片只用一种。A–H 是外观（调色、转场、字幕），可以叠在任一模式上；I、J 就是两种模式本身的完整写法。K 是唯一混用两种模式的风格，只在用户点名要它（或要模仿宇晖晖晖）时使用。

## A：柔光情绪

```text
请把我提供的 Valorant 素材剪成约40–60秒的柔光情绪流 montage；如果音乐和素材够撑，可以做成2–4分钟的长片。允许普通单杀、双杀和漂亮甩枪，不要求五杀。音乐以我提供的音源为准，按人声乐句组织段落，让温柔音乐和干净枪法形成反差。

节奏按片长定：1分钟以内每分钟约35–45刀；长片每分钟约20–30刀，中位镜头1–2秒，并安排几段4–10秒不切的长镜头，让一个完整的回合呼吸。剪点跟乐句和人声换气走，不追每个鼓点。

使用轻柔泛光、通透中间调、少量颗粒，色彩接近原片；保留HUD、小地图和击杀栏，让观众看得懂局势。可以保留输掉的回合或计分板，让片子有故事。重音处用短暂过曝、暗角辉光或轻微鱼眼光晕，随后回到清晰实速。慢动作放在开枪前的悬停或命中后的余韵。

歌词或原创短句用小号字幕，跟着人声进出，不整屏连续滚动。保留少量有质感的枪声，压低杂乱语音。间奏处让画面安静下来（一个长镜头或一次声音回落），结尾让音乐自然结束一个乐句，可以用一个长镜头作余韵。

先读取实际素材与音轨，输出带源时间码、音乐锚点和速度曲线的时间线，再制作预览。参考片无法播放时明确标记，这份方案是设计提案，不声称复刻作者效果。保留原文件；只声明实际生成并检查过的交付物。
```

## B：回忆拼贴

```text
请用我的 Valorant 录屏制作45–60秒（或2–3分钟）的回忆拼贴 montage，把不同时间的操作组织成一个有呼应的小作品。普通单杀、走位、切枪和地图空镜都可以使用，重点是结构和视觉创意。

开场2–3秒内给一个画面母题：可以叠一层原创的音乐播放器界面（歌名、进度条、几行歌词），也可以是一个特定构图。中段让母题以不同地图或武器重现，结尾回到同一构图形成闭环。用实际相似的准星位置、横拉方向、枪械运动或地图形状做匹配剪辑。

主要手法只选两种，例如带发光细边框的画中画加短闪回，或第三人称视角的彩色残影拖尾加遮罩揭示。主操作始终是视觉中心；辅助画面可以短暂冻结或缩成小框，再由其中一个接管全屏。操作主体正常播放，不用倒放伪造击杀。

回忆层和当前层可以有轻微色温或饱和度差异（例如回忆段降饱和），全片色彩保持统一。剪辑跟随乐句与重音，给高潮留强度。文字只承担章节或情绪提示，用原创短句；播放器界面里不要出现未授权的平台标志。

先检查素材里是否真的有可匹配的动作；没有就换转场方案，不编造源片段。列出源入出点、图层关系、音乐锚点，再交付预览与可修改的工程或时间线。保留原片，检查画中画与闪回有没有遮住关键击杀。
```

## C：冷色卡点

```text
请把我的 Valorant 素材剪成25–40秒的冷色卡点 montage，要短、锋利、有冲击力。普通单杀和双杀也能成为主镜头，优先选转火、甩枪、位移或开枪动作好看的片段。

开场0–2秒直接给漂亮动作。整体每分钟约50–70刀，中位镜头0.5–0.6秒，但不要平均分配：前段稍松，高潮5–8秒内最密，最短镜头可到0.13–0.2秒。剪点对准音乐的实际起音和切分。高潮前安排一次0.5–2秒的声音抽空或明显降低音量，再进入最后的爆发。

等待、转身、切枪适度加速，开枪前短暂减速，命中时落回清晰画面。使用方向一致的甩镜运动模糊、径向变焦模糊、短遮罩切换和少量RGB分离；放射速度线只留给一两个最强落点。闪白只放在高潮窗口，平段不闪。命中前后要能看清敌人和瞄准关系。

调色清冷、通透、高对比，暗处仍能辨人。枪声与音乐重音形成打击感，连续多杀保留真实动作顺序，不把不同回合包装成一个残局。歌词或标题少量图形化排版，不盖住准星。结尾停在回合胜利横幅或黑场淡出。

先输出实际素材与音乐对应的时间线及重点效果说明，再制作预览。检查变速接缝、音画卡点、插帧重影和闪帧是否堆积。保留原片与旧版本；缺少可用工具时交付可执行方案，并说明尚未渲染。
```

## D：R&B 律动

```text
请把我提供的 Valorant 素材制作成35–50秒的R&B律动 montage。整体轻松、帅气、有弹性，音乐用我提供的音源，跟随切分、贝斯与人声，不剪成全程重低音冲击。

挑选普通但干净的单杀、双杀、轻巧走位和切枪动作。每分钟约30–45刀，按短句组织镜头，保留少量自然停顿；有的击杀落在主拍，有的回应切分或人声停顿，由实际音轨决定。让枪声成为节奏的一部分，而不是用枪声盖住人声。

使用轻暖中性色和少量柔光。镜头以小幅弹性缩放、流畅推拉和方向匹配转场为主。变速尽量圆滑，交火核心回到实速，击杀后短暂停留再接下一个动作。重点落点可以突然切近，或出现一句短文字，随后让出画面空间。

不要把松弛剪成拖沓：删掉无意义跑图和长等待，用动作本身制造趣味。结尾让最后一杀、人物动作或切枪回应音乐收尾。

先读取实际素材，列出源时间码、音乐切分点、镜头顺序和音量处理，再做预览。目前没有实测参考对应这一风格，把它当作设计提案。保留原始素材，检查音画同步、文字位置和导出流畅度。
```

## E：空灵爆发

```text
请把我的 Valorant 素材做成30–45秒的空灵爆发 montage。前段有空间感，后段随音乐展开，视觉高潮集中而鲜明。素材不必是职业操作，少量漂亮单杀、狙击或技能衔接即可。

音乐使用我提供的音源。开场可以用一个5–10秒不切的长镜头建立氛围，画面带一点倾斜或缓慢旋转，或者先抽掉声音1–2秒再起。选择音轨里实际存在的上升或drop作为展开点，不凭空假设有drop。展开后剪辑密度逐步升高，最后6–8秒最密（约每秒2刀）；画面整体亮度也逐步提高，最后偏冷白。

高潮使用径向星芒、整屏柔色闪白和局部色散；同类效果最多用3–4次，彼此间隔几秒，不连续堆叠。也可以安排一段降饱和的近黑白段落，再在展开时恢复色彩。准星和目标区域保持可辨。

前段等待可以压缩，命中瞬间恢复清晰，余韵处短暂慢放。低帧率素材少用慢动作，插帧异常立即换方案。最后一个重音后留短余韵，让音乐自然收束。

先给实际源片段、音乐锚点和主视觉高潮设计，再制作预览。时间码必须来自读过的素材；参考无法播放时明确说明这是创作方案。保留原片，检查过曝、拖影、关键目标可见性与音乐同步。
```

## F：歌词排版 edit

```text
请把我的 Valorant 素材做成30–45秒的歌词排版 edit，风格接近 TikTok 上流行的 Valorant edit。音乐用我提供的音源，歌词或原创短句必须是我有权使用的内容。

结构分两段。前段约10–15秒：选无HUD或HUD很少的画面（检视武器、切枪、跑动、技能），歌词一词一镜，每个词只停0.3–0.6秒，用大号粗体字放在画面中央，再用遮罩让手臂、枪或角色挡住文字的一部分，看起来字在前景物体后面。后段进入带HUD的击杀，文字减少，让操作说话。

整体每分钟约55–60刀，中位镜头约0.5秒。用黑场淡入开场；画面使用较强泛光和局部过曝、方向性运动模糊和放射速度线，冷色或高饱和霓虹都可以，但全片统一一种。结尾用最后一杀加黑场淡出，或者停在一个词上。

文字做法：字体粗、字距紧，可以加纹理、发光或描边；放在主体后面时，遮罩边缘要干净，不能盖住准星和敌人。前景遮罩做不到时，改成文字放在画面空白处并跟随镜头运动，不假装做出了遮挡效果。

先读取素材，标出哪些片段有清楚的前景物体可以做遮罩，列出每个词对应的源片段和时间，再做预览。检查文字可读性、遮罩抖动、过曝细节和音画同步。保留原片；工具不支持遮罩时说明降级方案。
```

## G：击杀反馈卡点

```text
请把我的 Valorant 击杀片段剪成15–30秒的击杀反馈卡点短片，重点是击杀音效、击杀图标和音乐节拍的同步，适合发在抖音、TikTok 或 B站。

保留完整HUD和屏幕中央的击杀图标，不要用特效盖住它们，它们本身就是节拍。开头0–6秒用一段较轻的铺垫（音乐前奏或一个干净的击杀），在音乐明显变响的那一刻接上最好看的一杀。之后每分钟约70刀，中位镜头约0.5秒；连杀时让每一次击杀音效落在一个起音或鼓点上，必要时轻微变速对齐，但不改变击杀顺序。

转场用甩枪方向的运动模糊，高潮最后几秒用径向变焦模糊和色散，闪白只放在最后的高潮。音乐和游戏击杀音效都要听得到：击杀瞬间短暂压低音乐，或者选音色不冲突的段落。结尾停在 ACE、FLAWLESS、CLUTCH 等回合横幅，或者最后一杀的击杀图标上。

先列出每个击杀的源时间码、击杀音效时刻和对应的音乐起音，标出需要变速对齐的地方，再做预览。检查击杀音效有没有被音乐盖住、变速有没有改变动作逻辑。竖屏发布时先告诉我裁切方案，不要把HUD和击杀图标裁掉。
```

## H：整活梗向

```text
请把我的 Valorant 片段剪成20–40秒的整活梗向短片，主角是操作里的态度：嘲讽、反杀、离谱的时机或者意外的走位。

保留HUD和原始画面，基本不调色，让观众看清局势和对手位置。每分钟约50–60刀。笑点处可以用红色箭头或圈标出敌人、黑白定格半秒、突然放大，或者短暂放慢后再加速。音乐用我提供的音源，跟着节奏或台词点剪，可以在笑点前突然停音。

文字只写短的原创梗，不嘲讽真实玩家的ID，不保留其他玩家的语音或聊天内容，必要时把对手的名字打码。

先列出每个片段的源时间码、笑点位置和要用的标注方式，再做预览。检查标注是否挡住关键动作，节奏是否拖沓。保留原片。
```

## I：流畅长镜头（F 模式）

```text
请把我的 Valorant 素材剪成流畅长镜头 montage，全片只用这一种剪法，风格接近 B站“Esdeathのedit”系列：剪得少，每一次换回合都踩在音乐重音上。时长按素材定，通常60–110秒。音乐用我提供的音源，标题可以用一句歌词或情绪短句。

剪法：只在同一个回合里处理击杀，回合之间直接硬切。全程不加速。列出每个回合里每一杀的时刻：相邻两杀间隔5秒以内，原样保留不剪；间隔超过5秒，把中间切掉，从下一杀前约2秒接上，用同一视角硬切，让人看得出还是同一回合。第一杀前留约2秒，最后一杀后留0.5–1.5秒并停在CLUTCH、ACE或WON横幅上。残局的跑位和等待也照这个规则处理，不加速。

结构：开头放最好的一个连杀或残局片段的高潮，接一次闪白和约1.5秒的发光签名卡（用我的名字或ID），之后一个回合接一个回合。剪点放在回合交接处并对准音乐起音，回合内部不追鼓点。段落之间可以用检视武器加大号文字、大招动画或终结动画换气。

保留HUD、击杀栏和回合横幅。底部用小号中文歌词字幕跟着人声。调色偏冷或偏皮肤主色，饱和度略高于原片。闪白全片4–6次，只放在段落交接。结尾停在最强残局的回合横幅或签名卡上。

先列出每个回合每一杀的源时间码、每处cut的间隔秒数和接回点、对应的音乐锚点，再做预览。检查保留段有没有被加速、cut前后两杀是否真的隔了5秒以上、剪点是否落在重音上。保留原片。
```

## J：一枪一剪卡点（S 模式）

```text
请把我的 Valorant 素材剪成一枪一剪卡点 montage，全片只用这一种剪法，看点是神经枪和甩枪的速度。时长20–60秒。音乐用我提供的、节奏感强的快歌，比如 AJR《World's Smallest Violin》这类断奏弦乐，或 phonk、电子。

剪法：每个击杀单独一刀，按击杀顺序排，不同回合之间直接硬切。连杀和残局也拆成一个个单杀，保留原顺序，必要时加一行小字比如“1v4”。每刀0.3–1.0秒，拉枪过程保持实速，不慢放；只在命中后可以加0.2–0.4秒慢放余韵。

两种接法按音乐选：普通拍子用“一杀一刀”，入点就是看到敌人的那一帧，保留完整拉枪，开枪帧落在拍子上，击杀后0.1–0.2秒出。密集的断奏乐句用“一杀两拍”：先放看到敌人的0.15–0.3秒落在一拍，跳过瞄准，从开枪前2–3帧接上，开枪落在下一拍；多个击杀依次串成“看到人、开枪、看到人、开枪”。卡的是开枪帧，剪点略早于拍子。

全片每分钟约45–65刀，中位镜头约0.4–0.6秒。转场用沿拉枪方向的运动模糊和速度线；可以在中段留一个2–3秒的狙击或连杀镜头当换气。保留HUD和击杀图标。结尾停在回合胜利横幅或最后一杀。

先列出每一刀的源时间码（看到人的帧、开枪帧）、用的是哪种接法、对应的音乐拍点，再做预览。检查拉枪有没有被慢放或截掉、每一刀是否看得清命中、开枪是否落拍。保留原片。
```

## K：大转场情歌（宇晖晖晖式）

```text
请把我的 Valorant 素材剪成2–4分钟的大转场情歌 montage，风格接近抖音“宇晖晖晖”的合集。音乐用我提供的一首华语流行情歌，标题写成“第N集 | 一句情绪短句 #无畏契约 #歌名”。

这个风格混用两种剪法，按音乐段落切换：主歌和间奏用流畅长镜头，同一回合里相邻两杀间隔5秒以内原样保留，超过5秒切到下一杀前约2秒，不加速，开头可以放一个20秒以上不切的完整回合；副歌用一杀一刀的爆发，每刀0.6–1.6秒换一个回合，最密的地方2–3秒切十几刀接近频闪。全片每分钟约25–35刀，中位镜头约0.5–1.3秒，留10–18个超过4秒的长镜头。剪点对准音乐起音。

回合之间都用“大转场”：沿甩枪方向的强运动模糊，整屏糊开0.2–0.4秒再落到下一个回合；能找到同色或同形的画面时做匹配剪辑，比如狙击镜的圆接烟雾的圆、粉色接粉色。高潮段可以加整屏亮色闪帧、画面四边的紫色辉光边框，狙击段加黑金色的上下框。音乐停顿处用1–2秒黑场。

保留完整HUD、王牌精锐和完美团灭横幅。可以插入记分板画面，或者在死亡视角上定格约2秒再接下一段。故事里可以有“败北”回合，结尾停在“败北”横幅加记分板或结算动画，自嘲收尾。

先列出每段用哪种剪法、每个回合每一杀的源时间码、每处转场的方向和匹配关系、对应的音乐段落和拍点，再做预览。检查转场糊开时有没有盖住命中瞬间、长回合里有没有加速、闪帧是否过多刺眼。保留原片。
```

## 平台适配

- **B站横屏**：16:9，短片30–60秒，或情绪长片2–4分钟；可以保留作者水印与片尾卡。参考样本里的长片（R2、R3、R5）都在2分钟以上。
- **TikTok**：参考样本里热门 Valorant edit 多为16:9原画直接发布（T1、T3），也有1:1；前1秒必须有画面或文字钩子，时长多在40秒左右。
- **抖音**：实测的宇晖晖晖合集（播放 337 万–959 万）全部是16:9横屏原画、1.5–4.5分钟，竖屏不是必须的。
- **竖屏9:16**：没有实测。裁切时以准星为中心，HUD 与击杀图标用单独图层重新摆放，或者用上下模糊背景保留完整横屏画面；裁切方案先跟用户确认。

## 混合方式

优先让音乐决定主风格，素材决定转场和速度。例如 A 的柔光加 C 的高潮，F 的前段歌词加 G 的击杀卡点，E 的长镜头铺垫加 C 的爆发。一个短片通常只需要一个主风格加一种辅助手法；用户明确要多段风格变化时，按音乐段落安排并说明衔接方式。
